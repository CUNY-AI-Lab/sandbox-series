## Adventure Goals

Active custom model system prompt defines setting, goals, and rules. Read it before play. Ask about missing or contradictory instructions. Model must show how each prompt instruction maps into choices, state, conditions, effects, and endings before invocation

Reusable Conclude Adventures reads goals from that prompt and checks available evidence. It imposes no genre, source-detail goal, or ending. Sources are required only when a prompt goal depends on them. Immediate stop overrides further adventure steps; unfinished work is stopped, not completed
