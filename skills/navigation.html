Continue Saved Model

  1. Click New Chat (pencil icon) in left sidebar
  2. Choose saved model from model ID at lower right of message box

Your model name should appear below message box

Clone Custom Model

  1. Open Workspace, then Models
  2. Find STEM Adventure Games, open menu, and choose Clone
  3. Enter your own name and model ID; review settings and save

Actual editor after Clone shown; Clone menu and model Save & Create are not in this replacement capture

Use Earlier Sources

  1. Open your collection and instructions.txt
  2. Copy actual source passages and earlier scene

Preserve topic, audience, and source roles

Add Conclusion Skill

  1. Read Conclude Adventures example
  2. Open Workspace → Skills → Create
  3. Enter available Name and ID, Description, and complete Skill Instructions
  4. Review Access and Save & Create

Proposed example is not already installed; current Skills form shown

Test Your Skill

  1. Select your saved skill through Integrations → Skills
  2. Ask about absent source evidence
  3. Ask to stop with goals unfinished
  4. Record response and whether saved skill loaded

If no play record exists, do not claim completion; selected-skill submenu is uncaptured

Add Adventure Kit

  1. In saved model chat, click Integrations beside +
  2. Choose Tools and search Adventure Kit
  3. Turn on toggle

Capture uses DeepSeek with toggle off; use your saved adventure model and verify toggle on

Run Custom Scene

  1. Include saved scene and actual source passages
  2. Review model’s scene and choices before tool call
  3. Send completed custom scenario_json to render_adventure

No hosted custom request was run as part of preparation

Record Your Play

  1. Choose one action in your own scene
  2. Read displayed response and try Undo
  3. Paste observed record into chat

No suitable custom-game screenshot exists; use your own displayed scene

Copy Tool Code

  1. Open Workspace → Tools and select Adventure Kit
  2. Click inside code editor
  3. Use Select All and Copy; on this Mac ⌘A and ⌘C

Actual tool list shown; copy complete current code, including lines outside visible screen

Copy Skill Instructions

  1. Open your own saved skill or Conclude Adventures example
  2. Copy complete Name, Description, and Instructions
  3. Preserve original in notes

Example is proposed text, not an installed skill claim

Copy Proposed Skill

  1. Open Conclude Adventures from workshop resources
  2. Use complete Skill Instructions for original copy

Source and evidence checks plus immediate stop are part of its procedure

Revise With Support

  1. Open CAIL Workspace Support model card
  2. Confirm name below message box
  3. Paste original for revision, or describe purpose, input, and expected result for a new item
  4. Add observations, one requested change, and source passages

Support does not inherit your collection; read complete proposed revision before use

Create Revised Tool

  1. For tool path only, open Workspace → Tools → Create
  2. Enter new Name and ID
  3. Replace all sample code with complete revised code

Current Tools list exposes Create at upper right; current form shown next

Create Revised Skill

  1. For skill path only, open Workspace → Skills → Create
  2. Enter new Name and ID for version 2
  3. Paste complete revised Skill Instructions

Preserve your original copy; revise one completion condition

Access and Save

  1. Review Access at upper right
  2. Select Save & Create at lower right
  3. Check new item appears in its list

Tool form shown; skill form uses same corner locations. Access dialog and participant save result are uncaptured

Select New Version

  1. Open new chat with same saved model
  2. Select new item through Integrations → Tools or Skills according to chosen path
  3. Turn off older version of that item if selected
  4. Repeat identical input and record result

Verify saved skill loads separately; pasted directions alone test instructions
