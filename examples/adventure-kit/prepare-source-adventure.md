# Prepare Your Adventure

Use active custom model system prompt as the source of adventure setting, goals, and rules. Read its actual instructions before a scene draft. Preserve audience and any source roles it specifies

Ask model to show how each prompt instruction maps into scene choices, declared state, conditions, effects, and endings. If required context is absent or contradictory, ask one focused question. Confirm the draft before tool invocation

Sources are required only when a prompt goal depends on them. Separate supplied passages, fictional scene details, recorded tool results, and participant reports. Never infer retrieval or unseen play

Test with the existing STEM Adventure Games model as one configuration. Its STEM context belongs in that model system prompt and its resulting adventure data; reusable skill and tool contain no STEM, fantasy, room/item, or story content
